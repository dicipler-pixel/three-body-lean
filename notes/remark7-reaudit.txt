FLAGS CLOSED: POSITIVE DEFINITENESS AND THE -1 MONODROMY
-------------------------------------------------------------------------------
Both are now proved in ThreeBody/Basic.lean (not only in the referee file).

Positive definiteness. Two declarations:
  posDef_of_trace_det  a symmetric 2x2 real M with 0 < M.trace and 0 < M.det satisfies
                       0 < v 0 * (M *ᵥ v) 0 + v 1 * (M *ᵥ v) 1 for every v ≠ 0.
                       Division-free: a * (vᵀ M v) = (a v₀ + b v₁)² + (a d − b²) v₁²,
                       and a > 0 follows from a d > b² ≥ 0 together with a + d > 0.
  Q_posDef             the same for Q under the explicit hypothesis p 0 ^ 2 + p 1 ^ 2 < 4.
So "Q is positive definite near the origin" is no longer prose. Also formal: Q_symm, Q_trace (2),
Q_det (1 − r²/4), Q_gap_linear (trace² − 4 det = x² + y²), Q_equivariant (rot), Q_reflection (S),
so the family is genuinely invariant under the full D3 stabiliser and its gap is genuinely linear.

The -1 monodromy, exhibited by one continuous unit field evec φ = (cos φ/2, −sin φ/2):
  Q_eigen              Q at (r cos φ, r sin φ) times evec φ = (1 + r/2) • evec φ
  evec_unit            evec φ · evec φ = 1
  evec_half_orthogonal evec (φ + π) ⊥ evec φ
  Q_eigen_minus        Q at the same point times evec (φ + π) = (1 − r/2) • evec (φ + π)
  evec_flip            evec (φ + 2π) = − evec φ
So half a circuit swaps the two eigenlines and a full circuit returns the vector negated: that is
the -1 monodromy, row by row.

THE FORCED VERSION, IN THE RIGHT FORM: evec_monodromy
-------------------------------------------------------------------------------
What was left open after the first pass is now proved, and the earlier flag was wrong as stated.
Two facts:

1. As I first asked for it, the claim is FALSE. A continuous, nowhere-zero eigenvector field for
   the larger eigenvalue need not flip: at r = 1, w φ = (2 + sin (φ/2)) evec φ is continuous,
   nowhere zero, an eigenvector for 1 + r/2 everywhere, and w (3π) = -evec π ≠ -3 evec π = -w π.
   (Swarm smwt3ujh5, member m3, Lean-checked: .ultramath/smwt3ujh5/m3/Counterexample.lean.)
   The reason is that scalar multiples of an eigenvector are eigenvectors, so nonvanishing leaves
   the magnitude free.

2. With the norm fixed the flip IS forced. ThreeBody/Basic.lean now proves

     theorem evec_monodromy (r : ℝ) (hr : 0 < r) (w : ℝ → Fin 2 → ℝ) (hw : Continuous w)
         (hunit : ∀ φ, w φ 0 * w φ 0 + w φ 1 * w φ 1 = 1)
         (heig : ∀ φ, Q ![r * cos φ, r * sin φ] *ᵥ w φ = (1 + r / 2) • w φ) :
         ∀ φ, w (φ + 2 * π) = -w φ

   Structure of the proof, in the repo:
   - Q_dot_comm: Q is symmetric as a bilinear form (dot product can be moved across it).
   - Q_eigen_orth: a unit eigenvector for 1 + r/2 is orthogonal to the smaller eigenline, and this
     needs NO trigonometry: <Q v, z> = <v, Q z> gives (1 + r/2) <v,z> = (1 - r/2) <v,z>, hence
     <v,z> = 0 since r > 0. This replaced a half-angle computation with one line of linear algebra.
   - Q_unit_eigen: unit eigenvector for 1 + r/2 implies v = ± evec φ. With u = cos (φ/2),
     t = sin (φ/2), orthogonality is t v₀ + u v₁ = 0; then c := v₀ u − v₁ t satisfies
     v = c • evec φ and c² = 1.
   - esign: the sign function φ ↦ w φ 0 cos (φ/2) − w φ 1 sin (φ/2), continuous, values ±1.
   - constancy by the intermediate value theorem (mem_range_of_exists_le_of_exists_ge): a sign
     change would force a zero.
   - conclusion: w φ = esign φ • evec φ, and evec flips, so w does.

So the "forced" claim now holds in the only form in which it is true. What remains outside Lean is
unchanged and small: the tangent-plane identification and the Taylor step.
